# Repository Governance

## Maintenance & Updates
This repository contains canonical intellectual property. Updates are version-controlled and logged in `CHANGELOG.md`.

- **Versioning:** Semantic versioning (v1.0.0, v1.1.0, etc.). Breaking changes to framework definitions increment major versions.
- **Change Process:** All modifications are reviewed by the founder (Richard Schreiber) before merge.
- **Audit Trail:** Every framework file contains a source reference pointing to the Authority Canon or published book text.

## Canonical Integrity
- Framework names, definitions, and structural components are locked. Paraphrasing of canonical definitions is prohibited in commercial or published contexts.
- Statistics are sourced from verified anchors in the Authority Canon. No invented metrics.
- Voice standards: Practitioner register, urgency without alarm, specificity over abstraction, agency closes.
